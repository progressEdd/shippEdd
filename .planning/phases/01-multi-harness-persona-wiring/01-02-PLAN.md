# Plan 01-02: bootstrap asks the harness question and drives wire-agents.sh

**Objective:** Rewrite the bootstrap wizard's persona wiring so step 3b asks a harness question every run (fixed order per decision 3: pi, opencode, hermes, cursor, codex, claude, gemini, github copilot, custom) and drives `scripts/wire-agents.sh` — dry-run before the gate, diffs with replace-or-keep at the gate, real run after approval — and sync the skill's README. All edits land in the canonical master worktree (decision 10): `02-worktrees/master/bootstrap/SKILL.md` and `02-worktrees/master/bootstrap/README.md`; the vendored `.agents/skills/shippEdd/` copy in this checkout is refreshed later via the existing squash-merge flow and is never edited by this phase. Covers REQ-01 fully, the skill-side halves of REQ-03 (gate diff/replace-or-keep), REQ-04 (LLM inspection for custom), and success criterion 4 (gate receipt `wire   personas → <dir> (4 agents)`).

**Reconciliations this plan bakes in (from CONTEXT open questions):**
- Sequencing: step 1 no longer diffs personas against `.pi/agents/` — it only gathers *wired-dir evidence* to set the question's ➡️ recommendation. The diff moves into step 3b, after the harness answer, via `wire-agents.sh <harness> --dry-run [--diff]`.
- Custom interface: the skill (LLM) inspects the named dir's examples / the harness's docs and maps evidence to `--mode copy|inject|toml`; formats none of those express get hand-converted into a scratch dir wired via `--source` (plain md copy is the no-evidence fallback). The script stays deterministic (decision 9).
- Harness choice is never persisted or inferred — REQ-01 says the question is asked **every run**, including reruns; evidence only ever moves the ➡️.

**Out of scope:** `.pi/agents/` references in `02-worktrees/master/define/SKILL.md`, `02-worktrees/master/review/SKILL.md`, `02-worktrees/master/implement/scripts/slice-tasks.sh` (runtime dispatch, not bootstrap wiring) — leave them untouched. The vendored `.agents/skills/shippEdd/` tree in this checkout is likewise untouched (decision 10). amp and crush get no options, no mentions.
