# Plan 02-04: Retarget define/review/todo/wayfind — no _templates/_archive/runs conventions, SUMMARY-based gates, target frontmatter

**Objective:** EXEC-10's sweep across the remaining canonical skills: define and todo lose the `_templates` stash hop, review's plan gate and evidence derive from SUMMARYs + git log instead of run markers, review's ship step loses the archive, todo's phase numbering simplifies to the flat-forever world, wayfind's routing follows the new model — and the plan-approval/fix-plan specs gain the `target:` key.

Same convention as 02-01…02-03: canonical files under `02-worktrees/master/`, commit-spec lines use that prefix. Per Decision 1/10, define/review/wayfind keep their runs-dir *dispatch* flows untouched (their local `dispatch.sh` copies and their `<state>/runs/` marker reads for research/verify runs stay exactly as they are — they migrate in a later phase). Only references to *removed conventions* (`_templates`, `_archive`, implement's markers/replay) and the new `target` key change. The acceptance criteria grep for zero `_templates`/`_archive`/`done+committed` hits — if a stray reference beyond this edit list surfaces, fix it the same way (same-convention rewording), never leave it.
