# Plan 05-03: define/review/wayfind/todo migrate to the shared dispatcher — run-dir homes, products-first re-entry, review's rm -rf drop (DISP-01 references, DISP-02)

**Objective:** Migrate the four non-implement skills off `<state>/runs/` entirely. define and review dispatch through the suite-root shared dispatcher with transient state under the runs home (`runs-dir.sh home`; default `${TMPDIR:-/tmp}/shippEdd`) — prompt files, logs, and markers never under `.planning/` — and their re-entry gates flip from "markers are truth" to **products first**: RESEARCH.md / VERIFICATION.md verdict decide, REQUIREMENTS.md is the tiebreak when products are ambiguous, markers are advisory liveness (decision 5, AUTO-06's pattern generalized). wayfind reads the run board through the shared `--status` and speaks the same products-first law. review's ship step drops its `rm -rf <state>/runs` (DISP-02's closing of EXEC-10's transitional clause). todo loses its local state-dir.sh reference.

**cwd note:** fork of `master`; all paths worktree-root-relative. The per-skill `scripts/` dirs were deleted by 05-01; this plan touches prose only — every `scripts/state-dir.sh` / `scripts/dispatch.sh` reference becomes the shared path `.agents/skills/shippEdd/scripts/…` (written repo-relative in prose, per the AGENTS.md `~/`/relative law).

**Shared vocabulary (use these exact phrases so the skills stay in lockstep):** the **runs home** = `bash .agents/skills/shippEdd/scripts/runs-dir.sh home` (config-driven; default `${TMPDIR:-/tmp}/shippEdd`); the **phase run dir** = `<runs home>/<NN>-<slug>/`; the **products-first law** = "products first — durable artifacts decide; REQUIREMENTS.md is the tiebreak when products are ambiguous; markers are advisory, for live-watching only".
