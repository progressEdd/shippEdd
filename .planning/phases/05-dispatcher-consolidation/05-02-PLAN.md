# Plan 05-02: Config-driven work contexts and PR-by-default disposition — dispatch-plan modes, merge-back landing, implement docs + todo 08 (DISP-04, DISP-05, DISP-07)

**Objective:** Give the executor dispatch its two work-context modes and give merge-back its landing modes. `dispatch-plan.sh` consumes `runs-dir.sh mode`: worktrees mode (already built in 05-01) and **branch mode** — worktree-less repos run executors on a new branch in the main checkout, the repo switching branches mid-phase (invasiveness accepted, CONTEXT decision 4); researcher/verifier runs are untouched (they already work in the main checkout). `merge-back.sh` consumes `runs-dir.sh disposition`: **pr** (default) pushes the agent branch and opens a PR, keeping the branch as PR head, with a never-fail receipt fallback when `gh`/remote/push is unavailable (decision 11); **auto-merge** restores today's local `--no-ff` merge. `implement/SKILL.md` + `README.md` document the modes, fix todo 08's repo-specific example (DISP-07), and reference the shared scripts.

**cwd note:** fork of `master`; all paths worktree-root-relative (canonical skill tree). 05-01's contracts are frozen: `runs-dir.sh` queries (`home|mode|worktree-base|display|disposition`), config keys (`runs.mode`, `runs.dir`, `runs.absolute_paths`, `disposition`), layout `<base>/agent/<NN>-<slug>/<target>`, and `$shared="$here/../../scripts"`.

**Grep-anchored output strings kept byte-identical** (the selftest and SKILL.md quote them): `BUDGET: plan $id already used`, `REFUSED: plan $s_id is still executing`, `reused $target worktree (branch $agent)`, `re-attached branch $agent`, `landed $nn-$slug/$target → $target (already merged — nothing to do)`, `DRIFT: $agent stranded`, `CONFLICT: $agent stranded`, `merged $nn-$slug/$target → $target`.

**2. Disposition, between the drift check and the merge.** Insert after the `if [ "$mb" != "$fork_base" ] … fi` drift block:

```bash
if [ "$disposition" = pr ]; then
  remote="$(git remote | head -n1)"
  pr_fallback() {  # DISP-05 receipt fallback (decision 11): the run never fails
    local why="$1"
    echo "PR unavailable: $why (disposition: pr) — nothing merged, nothing deleted"
    echo "  branch $agent stays${agent_wt:+ (worktree $agent_wt left in place)}"
    echo "  options: open the PR by hand — git push ${remote:-<remote>} $agent && gh pr create --base $target --head $agent"
    echo "           or set \"disposition\": \"auto-merge\" in $state/config.json and re-run merge-back"
    exit 0
  }
  command -v gh >/dev/null 2>&1 || pr_fallback "gh CLI not found"
  [ -n "$remote" ] || pr_fallback "no git remote"
  gh auth status >/dev/null 2>&1 || pr_fallback "gh not authenticated"
  if url="$(gh pr view "$agent" --json url -q .url 2>/dev/null)" && [ -n "$url" ]; then
    echo "PR $url (already open) — agent branch $agent; nothing to do (disposition: pr)"
    exit 0
  fi
  git push "$remote" "$agent" || pr_fallback "git push to $remote failed"
  url="$(gh pr create --base "$target" --head "$agent" \
        --title "Phase $nn-$slug: merge into $target" \
        --body "shippEdd merge-back opened this PR (disposition: pr). Agent branch \`$agent\`, forked from \`$target\` at $(git rev-parse --short "$fork_base").")" \
    || pr_fallback "gh pr create failed"
  if [ -n "$agent_wt" ]; then
    git worktree remove "$agent_wt" \
      || { echo "HALT: worktree $agent_wt is not clean to remove — inspect it, remove it manually, then delete branch $agent" >&2; exit 1; }
    git worktree prune
  fi
  echo "PR $url — branch $agent pushed to $remote (disposition: pr); worktree removed; branch kept (PR head)"
  exit 0
fi
```
