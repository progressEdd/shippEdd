# Plan 03-01: Clear-context instruction at every phase-boundary handoff (POL-01)

**Objective:** POL-01 lands on canonical master: every skill handoff that names a next in-session command — review's ship step, define's step 8, implement's complete step, wayfind's exit, todo's promote exit, bootstrap's setup handoff — also tells the user to run it in a fresh/cleared session, and the repo README explains why that is safe (everything durable is on disk; STATE.md `next_action` is the router).

**cwd note:** your agent worktree is a fork of `master` — the skill files sit at the worktree root (`review/SKILL.md`, `define/SKILL.md`, …). They are NOT reached through any `02-worktrees/` path. All paths below are worktree-root-relative.

**The clause** (identical everywhere except wayfind's variant): append `— in a fresh session (clear this context first; everything durable is on disk)` to the existing handoff line. Do not reword the handoff lines themselves — the clause is additive.
